# STM32-Based Gimbal

**Independent Project | 2026 – Present | Ongoing**

## Overview
Development of a two-axis gimbal for active roll and pitch stabilization, combining mechanical design, embedded systems and feedback control. The project aims at future integration into the quadcopter platform.

## Technical Objectives:
-Mechanical design and assembly in Onshape
-Rapid prototyping using 3D printing
-STM32-based embedded control
-IMU integration for attitude estimation
-Sensor fusion
-PID-based roll and pitch stabilization
-Servo actuation
